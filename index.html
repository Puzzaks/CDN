1. Scope & Core Privacy Commitment

This Privacy Policy governs all mobile applications, games, open-source software, and web properties developed and published by Puzzak, including all releases on the Google Play Store under the page.puzzak.* namespace, source repositories under github.com/Puzzaks and github.com/Puzzak, as well as web pages hosted on puzzak.page and GitHub Pages. This policy also automatically applies to any future applications released by Puzzak unless superseded by a separate app-specific notice.

Core Principle: Puzzak software is built with a local-first, open-source mindset. Puzzak does not maintain proprietary user-tracking databases, does not sell or rent user data, does not set first-party tracking cookies, and does not keep user sessions on developer servers.

3. Mobile Platform Services & Third-Party SDKs

Depending on the features enabled in a specific current or future application, the software may interface with official Android system components or Google Play services:

  • Android AICore (On-Device AI): Used in apps such as PAIOS to run local generative models (Gemini Nano). All inference happens strictly on-device via Google's system-level AICore service without transmitting prompts or responses over the internet.
  • Google Play Games Services: Used in games such as Material 2048 to provide cloud saves, achievements, and global leaderboards. When signed in, Google processes your gamer profile ID and gameplay statistics.
  • Google Play Console & Firebase Crashlytics: Used to diagnose crashes and improve stability. If an app crashes, anonymized stack traces, device model, and Android OS version may be reported via Google's telemetry.
  • Android Auto Backup & Google Drive Sync: Standard Android OS feature that backs up local app preferences to your personal Google Drive account unless disabled in device settings.
  • Google Play Billing: Processes any optional in-app purchases, unlocks, or support donations directly through Google Play. Puzzak never views or handles your payment method details.

Reference: Google Privacy Policy • Firebase Privacy & Security

4. Websites, GitHub Pages & Cookies

This section applies to all web properties maintained by Puzzak, including puzzak.page, the Flutter MD3 Website project, and pages hosted on GitHub Pages (puzzaks.github.io / puzzak.github.io).

  • Zero First-Party Cookies or Sessions: Puzzak does not set first-party cookies, store server-side user sessions, or require accounts on web properties.
  • Google Analytics (Third-Party Cookies): Our web pages use Google Analytics to understand aggregate visitor traffic and page performance. Google Analytics sets cookies in your browser to collect anonymized traffic data. You can block these cookies via your browser settings, an ad-blocker, or the Google Analytics Opt-out Add-on.
  • GitHub Pages CDN Logs: Static pages hosted on GitHub Pages are served via GitHub Inc. and Fastly CDN, which log visitor IP addresses for security and network diagnostics per the GitHub Privacy Statement.

5. Security Policy, Open-Source Transparency & Contributions

Most Puzzak projects are released into the public domain under the Unlicense on GitHub, allowing anyone to audit the exact source code, network calls, and system prompts.

  • Security Scope (SECURITY.md): Because apps like PAIOS act as local interfaces for system services (such as Android AICore) and apps like PTK run strictly on-device, security updates focus on safe local API handling and dependency integrity. Only the latest published release on Google Play and the main branch on GitHub are actively supported with security patches.
  • Community Contributions & Translations (CONTRIBUTING.md): While English and Ukrainian localizations are maintained directly by Puzzak, community code contributions, bug reports, and translations (such as JSON localization PRs) are welcomed via GitHub Pull Requests. Contributors are credited in repository documentation and release notes (with special thanks to community contributors across PAIOS and TGCrawl including @abc0922001, @NewNiklas, @mikropsoft, @spageektti, and plugin inspiration from @kekko7072).

6. Data Control, Deletion & Contact

Because your application data lives on your own hardware, you can delete it immediately at any time by clearing the app's storage in Android Settings or uninstalling the application. Play Games leaderboard entries and cloud backups can be deleted directly inside the Google Play Games app settings.
